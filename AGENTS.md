# Na Lata — template pedagógico

Este projeto é um exercício colaborativo. Preserve os pontos de implementação dos alunos: não resolva outras issues como efeito colateral. Leia docs/CONTRATOS.md e a issue solicitada. Edite preferencialmente a pasta da entrega. Mudanças em core, navegação, pubspec e SQL precisam ser coordenadas com o professor. Não altere credenciais nem use service_role no cliente. Valide com flutter analyze e flutter test. Tarefas T01–T24 são IDs pedagógicos; números de issues GitHub estão em docs/ISSUES_GITHUB.md após publicação.
